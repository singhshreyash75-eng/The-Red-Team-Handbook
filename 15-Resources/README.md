## 9. Research Methodology

For every new security topic:

```text
Identify Topic
      ↓
Read Documentation
      ↓
Study Technical Research
      ↓
Reproduce in Lab
      ↓
Analyze Root Cause
      ↓
Document
      ↓
Build Practical Project
```

---

## 10. Resource Selection

Prefer resources that provide:

```text
Technical Accuracy
Practical Examples
Clear Methodology
Reproducible Results
Maintained Documentation
Primary Sources
```

Avoid relying solely on short tutorials or copied commands.
