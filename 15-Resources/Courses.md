
# Cybersecurity Courses

> Structured cybersecurity learning resources covering networking, Linux, web security, penetration testing, Active Directory, cloud security, and AI security.

## 1. Overview

Courses provide a guided progression from foundational concepts to practical security assessments.

Recommended progression:

```text
Networking
    ↓
Linux / Windows
    ↓
Programming
    ↓
Web Security
    ↓
Network Security
    ↓
Active Directory
    ↓
Cloud Security
    ↓
Advanced Research
```

## Key Takeaway

A strong cybersecurity learning plan combines:

```text
STRUCTURED COURSES
        +
HANDS-ON LABS
        +
TECHNICAL RESEARCH
        +
PERSONAL PROJECTS
```

Courses establish direction, while independent experimentation develops practical expertise.
